# Personal Brand Execution Protocol

This skill governs the development, design, and deployment of Idrees's personal brand website and supporting digital assets. Activate when working on the portfolio site, GitHub Pages deployment, or brand asset creation.

## 1. Project Structure
* Primary Workspace: `/home/idrees/personal_brand_site/IdreesQurashi.github.io/`
* Parent Directory: `/home/idrees/personal_brand_site/`
* Git Repository: IdreesQurashi.github.io (deployed via GitHub Pages)
* Live URL: https://idreesqurashi.github.io

## 2. Site Architecture
* `index.html`: Main landing page with Three.js interactive 3D canvas (`engine3d.js`)
* `agentic-lab.html`: Agentic systems showcase with workflow blueprints
* `outbound-engine.html`: Outbound automation engine demonstration
* `client-proof.html`: Client results and case study showcase
* `contact.html`: Contact and inquiry form
* `styles.css`: Global stylesheet
* `engine3d.js`: Three.js 3D interactive canvas engine

## 3. Design Standards
* For all visual, typographic, and layout decisions, activate the `frontend_design` skill which enforces the full creative direction framework.
* Core Requirements: Distinctive visual identity, anti AI aesthetics, information density with restraint, purposeful micro interactions.
* Asset Storage: Brand logo at `/home/idrees/personal_brand_site/brand_logo.png`. Favicon variants at `favicon.ico`, `favicon.png`, `favicon-32.png`, `favicon-128.png`.

## 4. Deployment Protocol
* Deploy via git push to the `main` branch of the IdreesQurashi.github.io repository.
* Verify deployment at the live URL after each push.
* Test responsive behavior across mobile and desktop viewports.

## 5. Content Strategy
* The site positions Idrees as an autonomous AI systems builder, not a generic developer.
* Showcase working automation architectures, live workflow demonstrations, and verified client deliverables.
* All copy follows the `copywriting_mastery` skill Mode 1 (Technical Backchannel) tone.
