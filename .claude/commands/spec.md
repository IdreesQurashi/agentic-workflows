# Spec Driven Development Slash Command

Execute the Spec Driven Development workflow for the specified feature or architectural component: $ARGUMENTS.

## Execution Instructions
1. Load and activate the `spec_driven_dev` skill.
2. Read `directives/workflows/01_spec_driven_development.md` for complete SOP governance.
3. Author the formal specification document under `docs/specs/` capturing problem statement, user journeys, invariants, and acceptance criteria.
4. Execute the adversarial ambiguity audit to probe edge cases and remove hidden assumptions.
5. Author the technical implementation plan under `docs/plans/` detailing file topology, schemas, and deterministic tool bindings.
6. Author the atomic task breakdown under `docs/tasks/` with explicit test verification commands.
7. Present the complete blueprint to the user for formal approval before modifying any code.
